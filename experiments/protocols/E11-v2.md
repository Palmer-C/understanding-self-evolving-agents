# E11 v2：更新时机的小规模工程试跑

2026-09-30，新协议与独立运行器；不修改或追写E11旧轨迹。离线验证与源文件清单保存后才可冻结。真实运行需要本对话另行批准，此文和匹配的预检文件本身均不是授权。

## 问题与范围

检查每任务、每两题、事件触发三个臂能否完成相同题序，并留下可重建的更新与资源记录。不是P5确认性检验，不据结果自动改判。固定顺序为per_task、periodic、event，服务时段可能混淆，不据此宣布单位资源收益排序。

题序按ID升序取offbyone前4题，再取mutabledefault前4题。只从train/select-valid/regression取题，不取sealed/heldout；清单在执行前固定。每臂8个episode，一次重复，一对任务族，切点4；三臂共24个episode。各臂从空记忆和相同题目初始文件开始。一个序列簇不产生总体置信区间，换族也同时改变题目难度和接口。稳定分布对照、多种切换方向与样本量设计留给独立后续协议。

## 时机、经验与因果顺序

当前题先做题并验收，再计算当前与历史前缀的信号，再决定构建经验。新经验最早用于下一题，不回改当前题判定。末题之后不构建。

三臂共同W=4次构建尝试配额，获准即消耗，失败、超长、空响应、重复或单段格式不符均不退款。每任务臂逐题请求；周期臂每完成两题提出请求，本例为第2、4、6、8题；末题请求保留，但不获准构建；事件臂采用OR：连续失败至少2、两个相邻长度2窗口失败率差绝对值至少0.5、当前任务描述相对于此前描述的二元组Jaccard新颖性至少0.5。初次输入新颖性取1。未形成两窗口时漂移为缺失，不填0。

每次构建一条1—120字符的单段经验；只传当前公开题目、实际可写Python源码和布尔判定，不直接传测试源码。允许从失败中提炼，但不把候选解释当真因。经验只做格式/去重准入，没有模型外的事实或迁移有效性验收；最多4条，全量顺序注入之后的任务。所有臂提示相同。做题Agent仍可以读取任务测试，这是历史实验台的可读只写保护边界，不得称为隐藏测试。生成Python在本地进程执行，不是操作系统级安全隔离。

## 共同资源约束与记账

- 每episode最多8次generate和12步；所有做题与经验generate共用每序列68次上限（8×8+4），三臂最多204次。这是调用机会共同上限，不是强行花满或相同实际token账。省下的经验配额不增加单题8次限制。
- 关闭原HTTP后端内部重试；新记录层每次generate至多1次初始传输调用及4次重试，共每序列340、全试跑1020次transport dispatch。dispatch表示调用HTTP后端的尝试，不证明服务端收到或计费。只对既有网络暂态、429及指定5xx等重试；402等确定性错误不重试。
- 每序列已知输入token阈值2,000,000、输出200,000、墙钟5400秒，均为下一次发送前检查的软停止阈值。每题原有200,000/20,000/600秒阈值也在调用前检查。后端未设置生成token硬限，单次回复或本地验证可能越过阈值，不能称费用硬封顶。没有价格/金额保证。
- 每次发送前写请求和pending条目，返回后写完整原始回复、usage、时长或脱敏错误类型/状态码。失败、进程中断留下的pending费用未知，不计作零；重试成功只补已知成功请求usage，不抹掉失败部分。成功响应缺有效usage也保留回复并停止序列，禁止静默当免费调用。
- 模型账以调用记录层为唯一合计来源，不再次累加episode trace中的同一usage。监测CPU、整序列墙钟、调用/重试墙钟分别报告；包含关系明确，不把重叠耗时相加。所有臂记录相同诊断信号，其本地监测开销不是事件臂独占，也不是API调用。
- 脚本后端的字符估算仅为离线预算测试，绝不进入模型能力或费用结果。共同预算中途耗尽为不完整序列，不将尚未完成题目填False。单题自己的调用预算耗尽后仍有真实本地验收，可作为该受限算法的题目判定。验证超时或无法启动另记基础设施缺失。

## 冻结、落盘与分析

默认仅生成预检，不请求模型。`--execute`须同时提供与当前代码、协议、完整题目hash匹配的`--approved-manifest`；此检查不能代替人的付费批准。每次使用独立E11v2 run ID；每臂/序列/重复目录只允许首次创建。不提供自动续跑选项；中断原件保留，任何另跑先审查剩余授权和失败账。

记录源代码与协议SHA-256、全部选题SHA-256、模型别名、base URL、温度与超时；不写API密钥。后端身份进入预检匹配，base URL只接受无嵌入凭据和查询参数的HTTPS地址，避免环境变化静默换后端。实验seed是记录标签，未发送给提供方，不能声称固定模型随机性。保存每题trace、每次经验来源与候选、发布/拒绝状态、前后记忆hash和逐步检查点。

完整三臂才调用e11_analysis_v2，分别计算event-periodic、periodic-per_task、event-per_task。先在一次重复内部切分前后段，质量差为成功率之差，优势扩大为后段优势减前段优势。此试跑只有1簇/1重复，CI留空。资源只报实际账，不从该分析器宣称单位资源收益已检验。任何缺臂或中断均不静默筛选成完整比较。

验收包括：真实本地沙箱跑通整条脚本序列、共同预算中断、付费调用防误触、缺usage、重试和终止错误、构建失败/拒绝、不覆盖、切点分析衔接。离线通过只说明测试覆盖的测量流程能工作。

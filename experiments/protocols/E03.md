# E03 / E03c：记忆的形式与持久物的拟合目标（协议）

> 协议先于实验（CHARTER §8）。本文件只规定**怎么做与怎么判**，不含任何实测数字。
> E01、E02、E03、**E03c**、E05、E11、E12 必须实测，不得降级为文献对照（CHARTER §8）。
> E03c 是首版必做且**不得降级**（`spec/outline-v0.4.md` §6.1、§6.2）。

---

## 1. 检验的命题

| 命题 | 内容 | falsifier |
| --- | --- | --- |
| **P3** | 记忆的**形式**比**容量**更决定跨任务迁移 | 结构化与摘要在跨任务族迁移上无差异 |
| **P3b** | 可移植性由**拟合目标**决定：拟合到问题域的持久物比拟合到求解器的更跨模型、跨 harness | 换模型后两类迁移收益无差异 |

**两个命题要分开，但不能分别跑两次**：`spec/outline-v0.4.md` §6.1 要求 E03c 与 E03
**共用同一批运行和同一条经验条目**，只在末尾增加一个"换读取者"检验臂。本协议据此把两者
合成一次运行：训练集上采一次来源轨迹，由同一批来源记录渲染出多条经验条目，再分两个轴检验。

## 2. 两个轴与臂的定义

### 2.1 轴一（E03）：记忆的形式

| 臂 | 形式 | 条目内容 | 渲染调用 |
| --- | --- | --- | --- |
| `form_raw` | 原始轨迹 | 该 episode 的工具调用序列与最后写下的代码，截断到固定长度，**不经任何模型加工** | 0 |
| `form_summary` | 摘要 | 由模型把同一条来源记录压缩成不超过 60 字的自然语言经验，不带任何结构字段 | 1 |
| `form_structured` | 结构化经验 | 由模型把同一条来源记录写成带字段的条目：事实 / `applies_when` / `does_not_apply_when` | 1 |

三个形式臂的**差别只在条目的组织方式**，来源记录、检索方式、注入位置、episode 预算全部同值。
`form_raw` 之所以不调用模型，是因为"原始"的定义就是不经加工；它因此天然比另两臂长，
这一点必须作为**已接受的混淆**写进结果——三臂比的是"形式"，而长度是形式的一部分，
不是可以单独扣掉的噪声（§7）。

### 2.2 轴二（E03c）：持久物的拟合目标 × 读取者

| 臂 | 拟合目标 | 读取者 | 说明 |
| --- | --- | --- | --- |
| `fit_solver_same` | 求解器 | 同模型 | 经验写成"针对当前这个模型的补丁"（第二人称，指名模型的倾向） |
| `fit_solver_cross` | 求解器 | **换模型** | 同上条目，换一个模型来读 |
| `fit_domain_same` | 问题域 | 同模型 | 经验写成"与谁读它无关的任务域事实/不变量"，带 `applies_when` / `does_not_apply_when` |
| `fit_domain_cross` | 问题域 | **换模型** | 同上条目，换一个模型来读 |

外加两个基线，其中换模型基线是 §6.1 的**硬要求**：

| 臂 | 作用 |
| --- | --- |
| `base_same` | 同模型、无记忆。"改进幅度"的零点，与 E01/E02 的基线同口径 |
| `base_cross` | **换模型、无记忆**。没有它就无法把"记忆可移植"与"另一个模型本来就更强/更弱"分开 |

`fit_solver` 与 `fit_domain` 的来源记录与 E03 三个形式臂**逐条同源**（§2.3），
否则两臂的差异会被"经验内容不同"混淆。

### 2.3 同源硬要求怎么落地

训练集上用**不带任何记忆**的 agent 跑 $E$ 个 episode，每个 episode 产生一条**来源记录**：
任务陈述、最后写下的代码、真实验收结果（通过/未通过）、验收输出原文、工具调用序列。

五条经验条目（`form_summary` / `form_structured` / `fit_solver` / `fit_domain` 四条模型渲染
加 `form_raw` 一条原样截取）**全部由同一条来源记录生成**，渲染次数与 token 记进副账。
这样 E03 与 E03c 共用同一批运行，且两轴的任何差异都不能归因到"经验内容不同"。

### 2.4 换模型臂的模型选择

换模型臂必须是一个**不同的模型**，不是同一模型换解码参数。本轮可用的第二个模型由
`experiments/lab/check_backend.py` 与后端 `/models` 接口实测确定，模型名写进运行结果。
硬要求（§6.1）：**换模型臂必须同时报告该模型的静态基线**——即 `base_cross`。
没有 `base_cross`，"换模型后收益下降"无法区分是记忆不可移植还是模型更弱。

## 3. 任务集、划分与"跨任务族"这条判据

任务集 `v1` 为 8 族 × 8 题，四个用途划分（train / select-valid / regression / sealed）各 16 题，
**每个划分里 8 个族各 2 题**（实测核对，见运行结果的配置节）。

这带来一个必须显式处理的问题：**P3 的预注册 falsifier 说的是"跨任务族迁移"，
而 v1 的 train 与 sealed 同族**（sealed 里没有 train 之外的族）。若直接拿 train → sealed 判 P3，
测到的是"同族新题迁移"，**弱于预注册口径**，属于降低 falsifier 标准，本协议不允许。

因此本轮跑**两套拆分**：

| 拆分 | 训练来源 | 判决集 | 测的是什么 | 用于 |
| --- | --- | --- | --- | --- |
| **A 族留出**（`holdout`） | 留出 2 个族之后，其余 6 个族的 train 题 | 被留出的 2 个族的全部可用题 | **跨任务族迁移** | **P3 的主判据** |
| B 标准划分（`standard`） | `train` 划分 16 题（8 族） | `sealed` 划分 16 题（8 族） | 同族新题迁移 | 与 E01/E02 可比性；P3b 的主判据 |

- 留出的 2 个族按预注册顺序取族名字典序的**最后两个**（`sortkey`、`strindex`），
  在运行前写死，不按结果挑选——按结果选留出族等于把噪声当成效应。
- **P3 只在拆分 A 上判**。拆分 B 的同族数字可以报告，但不得用来判 P3。
- **P3b 判的是换模型，不判跨族**，因此 P3b 在拆分 B（16 题，样本量较大）上判。
- 拆分 A 的可用题数远少于 16（本轮实测值写进结果），由此产生的判决力缺口按 §6 处理，
  **不得因为题少就改用拆分 B 去判 P3**。

## 4. 改进幅度怎么定义

- 主指标：判决集上每题 $R$ 次独立运行的 **pass@1 题均值**，由真实验收器给出，不是模型自评。
- 收益（gain）= 该臂 pass@1 − **同读取者的无记忆基线** pass@1，按 task_id 配对。
  - 同模型臂减 `base_same`；换模型臂减 `base_cross`。**跨读取者相减无意义**，一律不做。
- 迁移收益 $\Delta_{\text{migrate}}$（E03c 主观测）= 换模型臂的收益（相对 `base_cross`）。
  它回答的是"这份经验被另一个模型读到时还值多少"，而不是"另一个模型有多强"。
- 反号失效条数：同一条经验在同读取者下有益、换读取者后有害的条目数，由逐题收益符号翻转统计。
- 报告口径一律为**效应量（百分点）+ 95% 自助区间**，重采样单位为 task，不报裸 p 值
  （`experiments/lab/eval.py`）。

## 5. 指标与副账

| 类 | 指标 |
| --- | --- |
| 效果 | pass@1（题均）、相对同读取者基线的收益与区间、反号失效条数 |
| 机制 | 每条经验的字符长度（分形式统计）、检索命中条数、写入与渲染调用数 |
| 成本 | episode 数、模型调用数、prompt / completion token、墙钟秒数；渲染与写入走**副账**，不占 episode 配额 |
| 完整性 | 后端瞬时失败重试次数（静默重试等于改数据，必须进账） |

成本一律只报实物量。后端不返回价格，`Usage.usd` 恒为 `None`（已登记 `agent/BLOCKERS.md`），
折美元要等 P-1 定价表。

## 6. 判决规则

沿用 E01 §7 与 `spec/propositions.md` §3 的**更严口径**（2026-09-24 作者裁定）：

1. **未达预注册样本量一律停在 `open`**，这是最高约束；区间判据只在达到样本量后才启用。
2. 预注册 MDE = $0.03$；按 $n \ge (1.96\,s/\mathrm{MDE})^2$ 反推所需配对题数，
   $s$ 取本次运行实测的配对差标准差。
3. P3 的判决输入是拆分 A 上 `form_structured` − `form_summary` 的配对差：
   区间**包含** 0 → 触发 falsifier；**不含** 0 且达到样本量 → P3 获得支持。
4. P3b 的判决输入是拆分 B 上换模型后 `fit_domain_cross` − `fit_solver_cross` 的配对差：
   区间**包含** 0 → 触发 falsifier；不含 0 且达到样本量 → P3b 获得支持。
5. 无论点估计方向如何，**本运行器只出区间与原因，不改命题状态**。

## 7. 已接受的混淆（写进结果，不事后辩解）

1. **长度混淆**：`form_raw` 天然比 `form_summary` / `form_structured` 长得多。
   三臂比的是"形式"，长度是形式的一部分，本轮不设等长对照。
2. **结构化与领域化相近**：`form_structured` 与 `fit_domain` 都带 `applies_when` 字段，
   两者的渲染指令不同（一个要求结构化，一个要求与读取者无关），但产物可能高度相关。
   本轮不声称两个轴相互独立。
3. **换模型同时换能力**：换模型臂无法区分"经验不可移植"与"另一个模型用经验的方式不同"。
   `base_cross` 只能扣掉模型本身的强弱，扣不掉"对经验的利用率"。

## 8. 负结果预案

| 情形 | 处理 |
| --- | --- |
| 三形式收益区间全部跨 0 | 如实写"本轮不能区分记忆形式"，P3 停在 `open`，登记样本量缺口 |
| 换模型后两拟合目标区间跨 0 | 同上，P3b 停在 `open` |
| 换模型后**两臂都无收益**（都 ≤ 0） | 这是**负结果而非零结果**，照实报告，并报告 `base_cross` 以说明是否模型本身更弱 |
| `form_raw` 因长度过长被截断到与摘要不同源 | 在结果里写明截断长度与实际字符数，不声称"完整轨迹" |
| 任一臂 episode 全部失败（环境/接口问题） | 整轮作废重跑，不用部分数据凑结论 |

## 9. 与 E01 / E02 的关系

- **可比**：同为任务集 v1、同为 `Budget(max_calls=8, max_steps=12)`、同为 $R$ 次独立运行、
  同一套 `retrieve`（字符二元组、取前 2 条、不用族标签）、同一温度。
- **不可比**：E01 的 episode 内可调 `run_tests`，E02 六臂均不能，本实验沿用 E02 的**无验收工具**
  循环（来源记录来自训练期的真实验收，但 agent 在 episode 内看不到它）。
  因此**绝对数字不可与 E01 相减**，只能比标准化效应量并写明循环不同。
- 本实验的 `base_same` 与 E02 的 `arm_base` 机制相同；若两者数字不同，属运行间波动，
  不做交叉实验的差值推断。
